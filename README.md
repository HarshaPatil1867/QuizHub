# ⚡ QuizHub

An AI-powered quiz management platform with dual-role access for Students and Admins.
Built entirely with vanilla JavaScript — no frameworks, no external APIs.

## 🚀 Live Demo
[Click here to try QuizHub](https://harshapatil1867.github.io/QuizHub)

## ✨ Features

**For Students**
- Attempt assigned quizzes with a live countdown timer
- Track scores, accuracy, and progress across subjects
- View quiz history and performance analytics
- Take personal notes with color-coded organization

**For Admins**
- Create quizzes manually or using AI question generation
- Assign quizzes to students and monitor results
- View subject-wise performance dashboards
- Manage student records and scores

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- DOM Manipulation & Event-driven Architecture
- LocalStorage for data persistence
- Rule-based AI question generation engine

## 📁 How to Run
Just open `indexC5.html` in any browser — no installation needed!
